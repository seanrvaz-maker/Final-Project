# Final-Project
# Beyond Earth: Explore the Solar System

## Project Option

Responsive Website

## Project Description

Beyond Earth is an interactive educational website that allows users to explore the eight planets in our solar system. Users can navigate through different sections, select planets to view information, reveal additional facts, and complete a short space quiz. The website was built using HTML, CSS, and JavaScript and is designed to work on both desktop and mobile screen sizes.

## Theme Interpretation

The project responds to the theme of Space by focusing on outer space and our solar system. The website introduces users to the planets and presents information about space exploration in an interactive and visually engaging format.

## Intended User or Player

The website is intended for teenagers and adults who are interested in astronomy, science, space, or educational websites. It is designed for beginners, so the information is easy to understand and the interface is simple to navigate.

## User or Player Goal

The main goal is for users to explore the planets in the solar system, learn basic facts about each planet, and test their knowledge using the interactive quiz.

## Main Features

* Space-themed landing page
* Navigation menu
* About the Solar System section
* Interactive planet gallery
* Eight planet images
* Planet information display
* Show More and Show Less facts
* Interactive space quiz
* Quiz score and restart option
* Responsive desktop and mobile layouts
* Footer

## JavaScript Features

JavaScript controls several interactive parts of the website. Users can select a planet and dynamically display information about that planet. The selected planet is visually highlighted to provide feedback. The Show More button reveals an additional fact about the selected planet. JavaScript also controls the quiz by checking the selected answer, displaying correct or incorrect feedback, updating the score, disabling answers after a selection, and allowing the user to restart the quiz.

## Responsive Design

The website uses media queries to adapt to different screen sizes. On larger screens, the planet cards appear in multiple columns. On smaller screens, the cards move into two columns and eventually one column on phones. Navigation links wrap to fit smaller screens, images scale to fit their containers, and quiz buttons expand to make them easier to use on mobile devices. Text sizes, spacing, and card padding also adjust for smaller screens.

## User Testing

The prototype was tested by classmates and through self-testing. Testers were able to understand the purpose of the website and use the main interactions. The most important feedback focused on improving the visual design, layout, and spacing. Additional testing showed that interactive feedback and responsive behavior could also be improved.

## Revisions

After testing, several revisions were made to improve the website:

1. The spacing between sections, headings, planet cards, and other content was increased to create a cleaner layout.
2. A selected state was added to the planet cards so users can clearly see which planet they selected.
3. The Planet Information section was redesigned into a card with clearer spacing and organization.
4. The quiz was improved with correct and incorrect feedback, a visible score, disabled answers after selection, and a restart button.
5. The mobile layout was improved so planet cards stack on smaller screens and buttons are easier to use.
6. An About the Solar System section was added to provide more information and strengthen the overall content of the website.
